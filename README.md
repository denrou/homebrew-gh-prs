# homebrew-gh-prs

Homebrew tap for [gh-prs](https://github.com/denrou/gh-prs), a CLI for
listing the GitHub pull requests that need your attention.

## Install

```bash
brew install denrou/gh-prs/gh-prs
```

## How the formula stays current

`Formula/gh-prs.rb` is regenerated by the
[Update Formula](.github/workflows/update-formula.yml) workflow
(via [homebrew-pypi-poet](https://pypi.org/project/homebrew-pypi-poet/)),
triggered automatically by the
[release workflow](https://github.com/denrou/gh-prs/blob/main/.github/workflows/python-publish.yml)
in the main repository after each PyPI publish.
